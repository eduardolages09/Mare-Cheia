# Maré Cheia

Site dos apartamentos Maré Cheia, na Praia da Consolação, em Peniche.
Site estático (HTML, CSS e JS, sem build): abre `site/index.html` ou publica a pasta `site/`.

- `site/index.html` — a página de entrada, com os dois apartamentos.
- `site/apartamento-da-varanda/` e `site/apartamento-do-terraco/` — a página de cada apartamento.
- `site/assets/` — estilos, scripts, fotografias e vídeos.
- `netlify.toml` — publica só a pasta `site/`.
